# 開発者プラットフォーム一覧

2件のGeminiレポートから整理した74項目と、2026年10月21日時点の規模調査を閲覧する静的サイトです。

- `index.html`：データ・CSS・JavaScriptを含むページ。ブラウザーで直接開いても利用できます。
- `platform-catalog.xlsx`：元のExcel（5シート）。
- `.nojekyll`：GitHub Pagesで静的ファイルをそのまま配信する設定。

検索、地域・用途・数値確認状況の絞り込み、名前順、固定見出し・サイト名、詳細パネル、関連事例50件、比較・方針10件、抽出・規模調査レビューを収録しています。

数値の種類と集計時点は項目ごとに異なります。人数の単純ランキングは行いません。非表示の埋め込み3件は未確認という元の抽出範囲の制約も、ページの「出典・レビュー」に記載しています。

## 公開方法

GitHub Pagesの「Deploy from a branch」で`main`ブランチの`/(root)`を選択します。ビルド処理や外部ライブラリは不要です。外部フォントを読み込めない場合は日本語フォントの代替で表示します。

## デザイン

アイボリー・深緑の資料型デザイン。Noto Serif JP（見出し）、Noto Sans JP（本文）、IBM Plex Mono（英数字）。表は独立して縦横スクロールし、CSSのposition: stickyで列見出しとサイト名を固定します。スマートフォンでは詳細パネルを全幅に切り替えます。
